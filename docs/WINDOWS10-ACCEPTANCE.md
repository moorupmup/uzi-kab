# Проверка Windows 10 и принтера

Локально программа проверена на Windows 11. Целевую Windows 10 и реальную печать проверяет пользователь, как согласовано. Все пробные записи и восстановление ниже выполняйте только в отдельной тестовой папке.

## Подготовка

1. Закройте прежнюю программу. Сохраните отдельную копию всей рабочей папки, особенно `uzi.db`.
2. Перенесите папку «Кабинет УЗИ» на локальный диск. Требуется Windows 10/11 x64 и разрешение записи. Не используйте Program Files, сетевой диск или облачную синхронизацию. Оставьте свободное место минимум для трёх размеров базы: при обновлении и первом сохранении появляются копии. Для вложений потребуется больше.
3. Запустите «Проверить компьютер.cmd». Если нет WebView2, установите `requirements/MicrosoftEdgeWebView2RuntimeInstallerX64.exe` из комплекта. Это автономный установщик Microsoft; интернет для установки не нужен. Программа запускается обычным пользователем.
4. Создайте отдельную папку «ПРОВЕРКА — не рабочая база», скопируйте в неё новый exe и копию `uzi.db`. Тестовой базой не заменяйте рабочую.

## Первый запуск и архив

- Откройте «Кабинет УЗИ — новая версия.exe». Создайте первого администратора: своё имя, логин, пароль от 10 символов. Готового пароля нет, старые пароли не переносятся. Сохраните пароль в надёжном месте.
- Проверьте появление `backups/before-upgrade-*.db`. При обновлении также удаляются только пустые неизменённые заготовки без пациента после создания before-empty-cleanup-*.db; вкладки «Незавершённые записи» больше нет. Схема обновляется с версии 1 до 2; старые exe обновлённую базу не открывают.
- Откройте несколько знакомых архивных исследований разных видов. Сравните пациента, дату, врача, описание, заключение с исходной программой. Старые исследования редактируются напрямую. На тестовой копии измените заключение и параметр, сохраните и откройте повторно. Предыдущие значения остаются в журнале.
- Проверьте поиск по ФИО и номеру, размеры таблицы 50/100/200/500 и переходы страниц. Перезапустите и войдите снова.
- Повторный запуск той же базы должен предложить закрыть прежнее окно.

## Запись — только тестовая папка

- Создайте «Проверка Тестовая Карточка» без настоящих персональных данных. Сохраните адрес, откройте повторно. Неизвестную дату рождения можно оставить пустой.
- Создайте исследование щитовидной железы. Размеры правой доли 50 × 20 × 20 мм → «Пересчитать» → V1 = 9.58. Сохраните черновик, откройте заново.
- Измените размер: старый результат должен исчезнуть. Проверьте завершение и печать с неполными размерами без обязательного пересчёта. При необходимости пересчитайте, впишите «ТЕСТ. НЕ МЕДИЦИНСКОЕ ЗАКЛЮЧЕНИЕ» и завершите.
- Обозначение объёма «мм» сохранено по вашему решению. Пояснение о результате формулы в см³ должно быть на экране и в печати.
- Добавьте тестовый снимок, сохраните обратно и откройте. Проверьте короткое видео и перемотку. Воспроизведение зависит от кодеков Windows; AVI сохраняется для внешнего проигрывателя.
- Создайте второе завершённое исследование тому же пациенту. Выделите оба в карточке, сохраните комплект и откройте общую печать.
- Создайте тестовых пользователей «Врач» (со связью с врачом) и «Просмотр». Просмотр не может менять данные. Врач не может менять новое исследование другого врача или управлять пользователями и копиями. Старые исследования доступны для редактирования всем пользователям с правом записи. Администратор может скрыть и восстановить карточку без потери истории.
- В статистике выберите день теста: завершённые записи учитываются, черновики — нет. Сохраните CSV и проверьте кириллицу в Excel.

## Печать

1. Распечатайте «Тестовый протокол.pdf» из комплекта. В нём только вымышленные данные. Бумага A4; масштаб 100% или по размеру страницы; колонтитулы браузера отключить.
2. Распечатайте сохранённое исследование из тестовой программы. Проверьте отсутствие меню и полей редактора, читаемость кириллицы/см³, края, дату, номер, пациента, врача, заключение и место подписи.
3. Отметьте снимок «Включить в печать» и проверьте отдельную страницу. Распечатайте комплект: каждое исследование начинается с новой страницы. Проверьте длинное многостраничное описание.
4. Сравните несколько знакомых протоколов с оригиналом. Формулы перенесены без добавления диагностических порогов; медицинское содержание проверяет врач.

## Копии — восстановление только тестовой базы

1. После первой записи за день проверьте `backups/auto-ГГГГ-ММ-ДД.db`. Повторные записи в этот день не создают новую ежедневную копию.
2. В «База и копии» создайте ручную копию. Измените адрес тестового пациента и сохраните.
3. Восстановите ручную копию: ввод пароля администратора и слова «ВОССТАНОВИТЬ». Войдите снова. Старый адрес должен вернуться; состояние до восстановления находится в `before-restore-*.db`.
4. Восстановление возвращает также пользователей, пароли, вложения и комплекты на дату копии. Для копии до создания первого администратора потребуется создать его заново.
5. Регулярно переносите копии на другой носитель. Папка рядом с базой не защищает от поломки диска. Автоматического удаления копий нет. Встроенный вход не шифрует базу: ограничивайте доступ к файлам средствами Windows.

## Результат

Запишите версию/разрядность Windows, модель принтера и драйвер, результаты запуска, поиска, записи, вложений, прав, восстановления и печати. При сбое сохраните точный текст ошибки и отчёт «Проверить компьютер», избегая персональных данных.

После приёмки закройте тестовую папку. Для работы используйте свою рабочую базу и создайте в ней настоящего администратора. Тестовые учётные записи разработки в рабочую базу не добавляются.

Официальные материалы: [WebView2 Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/), [автономная установка и определение среды](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution).

- Откройте «Справочник шаблонов»: проверьте поиск, разделы и показ скрытых записей. В редакторе вставьте заготовку в заключение: уже введённый текст должен сохраниться.
