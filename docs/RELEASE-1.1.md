# Кабинет УЗИ 1.1 — дополнение рабочего кабинета

Запускайте **Кабинет УЗИ — новая версия.exe**. Рабочая база `uzi.db` при упаковке не заменяется. Перед первым обновлением программа создаёт проверенную копию; новый формат базы не открывается прежней программой.

Добавлено и проверено:

- Полноценный справочник: заготовки, вложенные разделы, перенос, копирование, порядок, удаление и восстановление. Есть обычная вставка и составная фраза с выбором частей.
- Настройка видов исследований, поддерживаемых версий форм и вариантов полей. Сохранённые документы используют свою форму и прежние подписи.
- Недостающие поля и условия рабочих форм. Измерения и пересчёт необязательны; неполные размеры не блокируют завершение.
- Черновики, удаление и восстановление исследований и комплектов, сохранённый предпросмотр и проверка состава перед печатью.
- Управление врачами без изменения подписей прошлых документов. Отчёты по видам и врачам, фильтры и подробные списки с CSV.

Сохранены принятый дизайн, компактные карточки и основные действия. Врач, администратор и просмотр — три роли, подтверждённые пользователем. Отчёт по группам заключений не включён по его решению. Регистратура, касса, расписание и общая амбулаторная карта остаются отдельным объёмом.

Перед работой прочитайте **Инструкцию для врача.html**. На отдельной копии пройдите **Инструкцию проверки.md**. Технические проверки не заменяют врачебную приёмку знакомых примеров, проверку реального принтера, файлов аппарата УЗИ, кодеков и целевой Windows 10.

В архиве подтверждено использование 16 версий форм. Ещё 171 версия без записей здесь учтена отдельно; для подключения дополнительных рабочих форм нужна отдельная сверка. Полный перенос всех общих возможностей исходного архива не заявляется.

Для возврата к прежнему exe после изменения формата нужна полная копия базы до обновления. Возврат базы возвращает все данные на момент копии; не выполняйте его на рабочей базе без осознанного решения.
