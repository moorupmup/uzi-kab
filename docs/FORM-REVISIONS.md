# Версии поставляемых форм

`src/catalog.json` остаётся исходным каталогом для архивных документов. Доработки рабочих форм описываются отдельно в `src/form-revisions.json`: код и версия формы, номер доработки, скрытые поля, варианты списков, ссылки на разделы справочника и параметры редактора. В компонентах нет условий по названию исследования или идентификатору вида из базы.

Rust применяет это описание при выдаче текущей формы для нового исследования. Редактор, настройки видов и сохранение используют согласованное описание. Новый снимок сохраняется существующим механизмом `form_snapshots` и `_form_ref`; дополнительная миграция не нужна. `presetRevision` обозначает версию поставляемого описания, `configurationRevision` по-прежнему обозначает версию настроек заказчика.

Снимки сохранённых исследований не обновляются. Если у старой записи ещё нет снимка, её форма восстанавливается из исходного каталога, а не из новых правил. При первом сохранении фиксируется именно эта прежняя форма. Создание на основе документа также сохраняет его форму. Для применения текущих правил создаётся новое исследование с выбором вида.

Изменённые стандартные списки объединяются с настройками заказчика в памяти. Собственные подписи и добавленные варианты сохраняются; новые стандартные варианты становятся доступны, снятые с использования коды остаются скрытыми. Исходные строки настроек не перезаписываются при открытии базы. Существующие разделы справочника используются по служебным ключам, а не по числовым ID.

У вариантов структуры `inputLabel` задаёт подпись действия в интерфейсе, а `label` сохраняет текст для печати. `referenceSection: str_text` ссылается на общий исходный раздел структуры; `referenceKey` указывает поле, куда записывается выбранный текст. Содержимое желчного пузыря использует `v_polosti`. Отмена выбора не изменяет данные, повторный выбор заменяет текст, смена структуры на обычный вариант очищает связанное уточнение.

Проверки: `npm test`, `cargo test --manifest-path src-tauri/Cargo.toml -- --test-threads=1`, `node tools/check-abdominal-form.mjs`, `npm run desktop:build`. Проверка интерфейса использует вымышленные данные и охватывает выбор разделов, сохранение, предпросмотр, прежние документы и ширины 1440/960.
