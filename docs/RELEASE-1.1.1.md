# Кабинет УЗИ 1.1.1

Обновлена рабочая форма «УЗИ брюшной полости» (BROOHO, версия формы 1).

- Убраны свободное поле «Протокол», единичные образования с их зависимыми полями, сегменты I–VIII, ЦДК и размеры от/до множественных образований, отдельное уточнение структуры печени и примечание желчного пузыря.
- Добавлен вариант «Сокращён на тощак», исправлены варианты стенок, содержимого и контуров. Изменения контуров применены ко всем одноимённым полям этой формы.
- Содержимое желчного пузыря выбирается из собственного справочника базы. Последний вариант структуры печени, поджелудочной железы и селезёнки открывает справочник структуры. Выбранный текст виден в редакторе, сохраняется и печатается.

Для передачи заказчику нужен только новый EXE. База и справочники заказчика остаются на месте. Изменения этой версии не добавляют таблиц, столбцов или миграций. Новая форма применяется к новым исследованиям; сохранённые исследования и документы, созданные на их основе, используют свою прежнюю форму. Редактирование старого документа не удаляет скрытые в новой форме значения.

Обновление через программу требует опубликованного GitHub Release `v1.1.1` с одним переносимым EXE и готовым GitHub SHA-256. Обычный push исходников обновление не создаёт. Базу, вложения и резервные копии в релиз включать не нужно.

Упаковка только программы: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/package-update.ps1`. После готовой сборки добавьте `-SkipBuild`. Файл будет в `release/updates/1.1.1/uzi-kab-1.1.1.exe`.
