# Завершение переноса

1. Формы, справочники, условия и расчёты используемых известных версий перенесены. Текст: 1 189 записей, 16 версий, без расхождений. Формулы: 120 наборов против исходного JavaScript. Неизвестные исторические версии показывают сохранённые параметры явно.
2. A4 печать, пояснение исходных единиц, черновики и комплекты реализованы. Единицы оставлены по решению пользователя. Физическую печать проверит пользователь по инструкции.
3. Ежедневные и ручные копии, проверка целостности, импорт, восстановление со страховочной копией реализованы и проверены тестами и настоящим exe на тестовой базе.
4. По решению пользователя 5 070 пустых заготовок удалены из рабочей картотеки после проверенной копии; вкладка незавершённых записей убрана. Исходные таблицы сохранены.
5. Комплекты, статистика/CSV, вложения внутри базы, пользователи/роли, смена пароля и блокировка реализованы. Ограничения проверены на стороне Rust.
6. Выпуск Windows x64 собран. Локально проверено на Windows 11. Подготовлены инструкция Windows 10/принтер и автономный установщик WebView2 с подписью Microsoft. Целевую приёмку выполнит пользователь, как согласовано.

Рабочая база не заменялась. Запись и восстановление проверялись на отдельных копиях и синтетических данных. Границы проверки указаны в README.
