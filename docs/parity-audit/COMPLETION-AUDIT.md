Команды последней технической проверки: `npm test` — 31 тест; `cargo test --manifest-path src-tauri/Cargo.toml` — 44 теста; `npm run desktop:build` — успешно; `powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/package.ps1 -SkipBuild` — успешно; `python tools/check-release-package.py` — успешно. Native-сценарии запускались на изолированных учебных базах либо копиях архива; рабочая база не использовалась для записи тестовых данных.

При дополнительной сверке имеющийся release/uzi.db не совпал с замороженной копией побайтно только в пяти байтах служебного заголовка SQLite. Все байты начиная с offset 100 совпали; размеры, таблицы, количество и содержание записей не изменились. Прежний exe побайтно равен замороженному. Это отличие заголовка не выдаётся за равенство SHA-256; упаковка отдельно проверила отсутствие каких-либо изменений обеих действующих баз до/после операции.

## Внешняя приёмка и отдельный объём

В [WINDOWS10-ACCEPTANCE.md](../WINDOWS10-ACCEPTANCE.md) подготовлены действия на отдельной копии:

- Врач сравнивает знакомые обезличенные примеры 16 использованных версий, подписи/единицы, условные ветви и расчёты; подтверждает нужное поведение выбора по полу. Технические проверки не подтверждают клиническую правильность.
- На целевой Windows 10 проверяются реальный принтер, файлы аппарата УЗИ и необходимые кодеки, включая внешнее воспроизведение AVI.
- 171 версия без использования в представленном архиве учтена; подключение дополнительных рабочих форм требует отдельной сверки. Отсутствие записей не считается доказательством ненужности формы.
- Регистратура, расписание, касса, амбулаторная карта и общие модули оставлены отдельно по ответу пользователя. Произвольные роли и отчёт по группам заключений не требуются.

Выпуск подготовлен для локальной передачи и этой внешней приёмки. Полный клинический паритет всех 187 исходных форм, проверка оборудования и публикация в интернете не заявляются.
