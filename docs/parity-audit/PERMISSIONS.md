# Права текущей версии

Проверка по обработчикам src-tauri/src/main.rs, Security::require и прикладным проверкам. Основные роли сохранены: администратор, врач, просмотр. Произвольные группы старой системы пока не перенесены; вопрос об их необходимости задан отдельно, ответа нет. Это не считается подтверждённым отказом от них.

Печать удалённого исследования запрещена. В комплекте удалённый/недоступный/чужой пациенту документ не исключается молча: печать блокируется до разрешения проблемы. Изменённый состав требует проверки, а непосредственно перед печатью сверяется с показанными ID и revision. Эти ограничения одинаковы для всех ролей.

Скрытие врача не отключает учётную запись. Оно запрещает новые назначения, сохраняя прежние подписи и возможность правки уже назначенных исследований. Имя учётной записи, карточка врача и подпись сохранённого документа являются разными значениями.

CSV — чтение данных с сохранением нового файла пользователем, не изменение базы. Роль просмотра может выгружать доступный ей отчёт. Существующие файлы не перезаписываются. Значения, похожие на формулы таблиц, экранируются.
